Primeiro: qual é a diferença?

C e C++ compartilham raízes e muitos conceitos, mas não são a mesma linguagem.

C

Procedural e direto

Foca em funções, estruturas, ponteiros e controle explícito dos recursos. É comum em sistemas embarcados, sistemas operacionais e software de baixo nível.

C++

Multiparadigma

Suporta programação procedural, orientação a objetos, genéricos e recursos modernos da biblioteca padrão, mantendo forte controle sobre desempenho.

Em comum

Desempenho e proximidade

Ambas permitem trabalhar de forma muito próxima do hardware e oferecem grande controle sobre memória e representação de dados.

Muitas bibliotecas do C possuem versões/headers correspondentes no C++, além de recursos próprios da linguagem.

C++

<iostream>

Entrada e saída por streams com std::cin e std::cout.

C++

<string>

Oferece std::string, que gerencia dinamicamente seus caracteres e evita boa parte do gerenciamento manual de arrays de char.

C++

<vector>

Container dinâmico que gerencia automaticamente sua memória e pode ser redimensionado conforme necessário.

C++

<algorithm>

Disponibiliza algoritmos genéricos, como ordenação, busca e várias operações sobre ranges e containers.

⚠️ Atenção à portabilidadeHeaders como unistd.h e pthread.h não pertencem ao padrão ISO C e são associados principalmente a sistemas POSIX. windows.h é específico da API do Windows. Bibliotecas como SDL também são externas. Em C++, a situação é semelhante: bibliotecas de sistema e frameworks não fazem parte da biblioteca padrão da linguagem.

O mesmo problema, duas abordagens

Leia os exemplos e observe onde C++ adiciona abstrações sem abandonar a possibilidade de controle.

C puro 
#include <stdio.h>
#include <string.h>

int main(void) {
    char nome[50];

    printf("Digite seu nome: ");
    fgets(nome, sizeof(nome), stdin);

    printf("Olá, %s", nome);
    return 0;
}
C++ 
#include <iostream>
#include <string>

int main() {
    std::string nome;

    std::cout << "Digite seu nome: ";
    std::getline(std::cin, nome);

    std::cout << "Olá, " << nome;
    return 0;
}
5

Memória e responsabilidade

A diferença não é simplesmente “manual versus automático”: C++ oferece abstrações para tornar o gerenciamento mais seguro e expressivo.

C

Alocação explícita

Funções como malloc() e free() dão controle direto. É essencial verificar retornos e liberar corretamente os recursos.

C++

RAII e recursos

Objetos podem assumir e liberar recursos automaticamente. Containers e smart pointers reduzem a necessidade de chamadas explícitas a delete.

Boa práticaEm C, sempre verifique o retorno de funções de alocação. Em C++, prefira abstrações da biblioteca padrão antes de recorrer ao gerenciamento manual.
6

Como reconhecer C puro?

Use estes sinais como uma lista de verificação durante a leitura de um programa.

✓ Headers C

stdio.h, stdlib.h, string.h, math.h etc., quando fazem parte do programa e da biblioteca padrão.

✓ Estruturas

Funções, struct, ponteiros e organização em arquivos .h e .c.

✗ Recursos exclusivos de C++

Para caracterizar C puro, não devem aparecer recursos como classes, templates, std::cout/std::cin, new/delete ou outras construções exclusivas de C++.
