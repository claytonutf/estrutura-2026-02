Encadeada

Entenda como funciona a estrutura de dados mais fundamental da computação — do ponteiro ao nó, do nó à memória.

// 01 — Conceito

O que é uma Lista Encadeada?

Ao contrário de um array, os elementos não ficam em posições contíguas de memória. Cada elemento aponta para o próximo, formando uma cadeia de ponteiros.

✦ Tamanho dinâmico

Cresce e encolhe em tempo de execução com malloc() e free(). Alocação sob demanda, sem exigir um bloco contíguo para todos os elementos.

⇄ Inserção eficiente

Depois de localizar a posição, inserir um nó exige apenas o ajuste de alguns ponteiros. A localização da posição pode custar O(n).

↗ Acesso sequencial

Para chegar ao nó N é preciso percorrer N-1 nós. Não há acesso aleatório por índice.

⚙ Gerência manual

O programador controla cada alocação (malloc()) e desalocação (free()). Responsabilidade total.

// 02 — Estrutura

Anatomia do Nó

O código define duas structs e um typedef que trabalham juntos.

structs.cpp 
// Dados do aluno
typedef struct aluno {
    int   matricula;       // chave
    char  nome[30];        // nome
    float n1, n2, n3;      // notas
} aluno;

// Nó da lista
typedef struct elemento {
    aluno dados;                 // informação
    struct elemento *prox;       // próximo nó
} elemento;

// Alias para ponteiro para o primeiro nó
typedef elemento *Lista;
Por que Lista é um ponteiro?
typedef elemento* Lista define que Lista é um ponteiro para o primeiro nó. Quando a lista está vazia, ele vale NULL.
Ponteiro para ponteiro (Lista*)
As funções recebem Lista* (ponteiro para ponteiro). Isso permite alterar o endereço do primeiro nó dentro da função — essencial para inserções no início.
char nome[30]
O nome é um array de char de tamanho fixo — recurso nativo da linguagem C. Para strings flexíveis use uma cadeia de caracteres (`char`) ou outra estratégia apropriada em C.
// 03 — Operações

As principais funções da lista

A página acompanha seis funções fundamentais: criar, inserir, remover, medir, imprimir e liberar a lista.

cria_lista()

Aloca dinamicamente um ponteiro para Lista e inicializa a lista com NULL.

cria_lista() 
Lista *cria_lista() {
    Lista *li = malloc(sizeof(*li));

    if (li != NULL) {
        *li = NULL; // lista começa vazia
    }

    return li;
}

insere_lista_ordenada()

Percorre a lista comparando matrículas até achar a posição correta, depois redireciona os ponteiros.

1

Aloca novo nó

elemento *no = malloc(sizeof(elemento)) — reserva memória na heap para o nó e copia os dados do aluno.

2

Avança até a posição correta

Loop while compara atual->dados.matricula < al.matricula e avança ant e atual enquanto a posição correta não é encontrada.

3

Inserção no início (ant == NULL)

O novo nó passa a ser o primeiro: no->prox = *li; *li = no.

4

Inserção no meio / fim

no->prox = atual; ant->prox = no — o nó anterior passa a apontar para o novo, que por sua vez aponta para o restante da lista.

insere_lista_ordenada() 
int insere_lista_ordenada(Lista *li, aluno al) {
    if (li == NULL) {
        return 0;
    }

    elemento *no = malloc(sizeof(*no));

    if (no == NULL) {
        return 0;
    }

    no->dados = al;
    no->prox = NULL;

    elemento *ant = NULL;
    elemento *atual = *li;

    // Procura a posição correta.
    while (atual != NULL &&
           atual->dados.matricula < al.matricula) {
        ant = atual;
        atual = atual->prox;
    }

    // Inserção no início.
    if (ant == NULL) {
        no->prox = *li;
        *li = no;
    }
    // Inserção no meio ou no final.
    else {
        no->prox = atual;
        ant->prox = no;
    }

    return 1;
}

remove_lista_final()

Percorre até o último nó, desconecta o penúltimo e libera a memória.

remove_lista_final() 
int remove_lista_final(Lista *li) {
    if (li == NULL || *li == NULL) {
        return 0;
    }

    elemento *ant = NULL;
    elemento *no = *li;

    // Percorre a lista até o último nó.
    while (no->prox != NULL) {
        ant = no;
        no = no->prox;
    }

    // Se era o único nó, a lista fica vazia.
    if (ant == NULL) {
        *li = NULL;
    }
    // Caso contrário, o penúltimo passa a ser o último.
    else {
        ant->prox = NULL;
    }

    free(no);
    return 1;
}

libera_lista()

Percorre todos os nós e libera a memória de cada um — evita memory leak.

Memory leak acontece quando você free() o ponteiro da lista mas esquece de liberar cada nó individualmente. Cada malloc() deve ter exatamente um free() correspondente.
libera_lista() 
void libera_lista(Lista *li) {
    if (li != NULL) {
        elemento *no;

        while (*li != NULL) {
            no = *li;
            *li = (*li)->prox;
            free(no);
        }

        free(li);
    }
}
// 04 — Memória

Stack vs Heap

Nesta implementação, os nós são alocados dinamicamente na heap. O ponteiro inicial (li) fica na stack.

📥 Stack

Variáveis locais (li, i, no, ant, atual). Gerenciadas automaticamente — surgem na chamada da função e somem no retorno.

🔧 Heap

Os nós alocados com malloc(). Ficam vivos até você chamar free(). O ponteiro da lista (*li) também está aqui.

⚠ Memory Leak

Se o programa terminar sem chamar libera_lista(), a memória alocada deixa de ser acessível pelo programa — caracterizando um vazamento de memória durante a execução.

// 05 — Complexidade

Análise de Desempenho

Cada operação tem um custo. Conhecê-lo ajuda a escolher a estrutura adequada.

Operação Complexidade Motivo
cria_lista() O(1) Apenas uma alocação e uma atribuição.
insere_lista_ordenada() O(n) Percorre até achar a posição certa — até n nós no pior caso.
remove_lista_final() O(n) Precisa chegar ao último nó — percorre toda a lista.
tamanho_lista() O(n) Conta nó por nó sem cache de tamanho.
imprime_lista() O(n) Visita todos os n nós para imprimir.
libera_lista() O(n) Desaloca cada um dos n nós individualmente.
Inserção no início (variação) O(1) Não é ordenada, mas possível com a mesma estrutura.
Dica de otimização: Armazenar o tamanho na própria estrutura reduz tamanho_lista() de O(n) para O(1). Já remove_lista_final() só pode ser O(1) de forma direta quando a estrutura mantém informação suficiente para localizar o predecessor do último nó, como em uma lista duplamente encadeada.

Código-fonte Anotado

lista_encadeada.c 
/* lista_encadeada.c */

#include <stdio.h>
#include <stdlib.h>

/* ── DADOS ─────────────────────────── */
typedef struct aluno {
    int   matricula;
    char  nome[30];
    float n1, n2, n3;
} aluno;

/* ── NÓ DA LISTA ───────────────────── */
typedef struct elemento {
    aluno dados;
    struct elemento *prox;
} elemento;

typedef elemento *Lista;

/* ── CRIA ──────────────────────────── */
Lista *cria_lista() {
    Lista *li = malloc(sizeof(*li));

    if (li != NULL) {
        *li = NULL;
    }

    return li;
}

/* ── LIBERA ────────────────────────── */
void libera_lista(Lista *li) {
    if (li != NULL) {
        elemento *no;

        while (*li != NULL) {
            no = *li;
            *li = (*li)->prox;
            free(no);
        }

        free(li);
    }
}

/* ── TAMANHO ───────────────────────── */
int tamanho_lista(Lista *li) {
    if (li == NULL) {
        return 0;
    }

    int cont = 0;
    elemento *no = *li;

    while (no != NULL) {
        cont++;
        no = no->prox;
    }

    return cont;
}

/* ── INSERÇÃO ORDENADA ─────────────── */
int insere_lista_ordenada(Lista *li, aluno al) {
    if (li == NULL) {
        return 0;
    }

    elemento *no = malloc(sizeof(*no));

    if (no == NULL) {
        return 0;
    }

    no->dados = al;
    no->prox = NULL;

    elemento *ant = NULL;
    elemento *atual = *li;

    while (atual != NULL &&
           atual->dados.matricula < al.matricula) {
        ant = atual;
        atual = atual->prox;
    }

    if (ant == NULL) {
        no->prox = *li;
        *li = no;
    }
    else {
        no->prox = atual;
        ant->prox = no;
    }

    return 1;
}

/* ── REMOÇÃO FINAL ─────────────────── */
int remove_lista_final(Lista *li) {
    if (li == NULL || *li == NULL) {
        return 0;
    }

    elemento *ant = NULL;
    elemento *no = *li;

    while (no->prox != NULL) {
        ant = no;
        no = no->prox;
    }

    if (ant == NULL) {
        *li = NULL;
    }
    else {
        ant->prox = NULL;
    }

    free(no);
    return 1;
}

/* ── IMPRESSÃO ─────────────────────── */
void imprime_lista(Lista *li) {
    if (li == NULL) {
        return;
    }

    elemento *no = *li;

    while (no != NULL) {
        printf("Matrícula: %d\n", no->dados.matricula);
        printf("Nome: %s\n", no->dados.nome);
        printf("Notas: %.1f %.1f %.1f\n\n",
               no->dados.n1,
               no->dados.n2,
               no->dados.n3);

        no = no->prox;
    }
}
