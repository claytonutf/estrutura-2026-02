Pilha dinâmica encadeada

Elementos alocados com malloc() à medida que entram no topo e liberados com free() à medida que saem. Explore, empilhe e desempilhe de verdade.

O que é

Uma pilha dinâmica encadeada é definida com alocação dinâmica e acesso encadeado. Cada elemento é uma estrutura com dois campos: dados, que guarda a informação inserida, e prox, um ponteiro para o próximo elemento da pilha.

Além dos elementos, a pilha usa um ponteiro para ponteiro para guardar o “topo”. Assim, para trocar o primeiro elemento basta mudar o conteúdo desse ponteiro. O último elemento aponta para NULL, pois depois dele não há nada alocado.

Uma pilha vazia é aquela em que *pi == NULL.

Vantagem

Melhor uso da memória: não é preciso definir o tamanho da pilha previamente.

Desvantagem

Para destruir a pilha (e para saber seu tamanho) é preciso percorrê-la inteira.

Use quando não há necessidade de garantir um espaço mínimo para a aplicação ou quando o tamanho máximo da pilha não é bem definido.

Simulador interativo

Cada elemento mostra o campo de dados (struct aluno), o campo prox e um endereço fictício. O topo é sempre o primeiro elemento, apontado por *pi.

Tipo opaco e modularização

O usuário só enxerga um ponteiro do tipo Pilha*. Ele não sabe como a pilha foi implementada e só acessa as funções que a manipulam. Por isso, trocar a implementação não afeta o programa que a utiliza.

PilhaDin.h (visível)

Define struct aluno, o novo nome typedef struct elemento* Pilha e as funções disponíveis.

PilhaDin.c (oculto)

Define struct elemento (com dados e prox) e implementa as funções do .h.

O typedef esconde um dos ponteiros: Pilha* pi; serve tanto para a pilha sequencial estática (ponteiro) quanto para a dinâmica encadeada (ponteiro para ponteiro).

Inserção, remoção e consulta mexem só em alguns ponteiros, independentemente do número de elementos.

Pilha implementada com lista

Uma pilha é uma lista sujeita a uma ordem de entrada e saída, com inserção e remoção sempre na mesma extremidade. Por isso, dá para encapsular as funções da lista dinâmica encadeada:

Consulta

Sempre o primeiro elemento da lista.

Inserção

Sempre no início da lista.

Remoção

Sempre no início da lista.
