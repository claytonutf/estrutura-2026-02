01 • Conceito fundamental

O que é um ponteiro?

Uma variável normalmente armazena um valor. Um ponteiro armazena o endereço de memória de outra variável.

x

Variável

É uma região da memória identificada por um nome e utilizada para armazenar um valor.

&

Endereço

O operador & permite obter o endereço de uma variável na memória.

*

Ponteiro

Uma variável capaz de armazenar o endereço de outra variável.

02 • Os dois operadores essenciais

03 • Primeiro programa

Ponteiro na prática

Observe como o ponteiro pode modificar diretamente o valor da variável.

ponteiro.c 
// Ponteiros em C

#include <stdio.h>

int main(void)
{
    int numero = 10;

    int *ponteiro;

    // Guarda o endereco de numero
    ponteiro = №

    printf("Valor de numero: %d\n", numero);

    printf(
        "Endereco de numero: %p\n",
        (void *)&numero
    );

    printf(
        "Valor apontado: %d\n",
        *ponteiro
    );

    // Altera numero por meio do ponteiro
    *ponteiro = 50;

    printf(
        "Novo valor de numero: %d\n",
        numero
    );

    return 0;
}
04 • Ponteiros e funções

Alterando valores dentro de funções

Passando o endereço de uma variável para uma função, podemos modificar a variável original.

funcao.c 
#include <stdio.h>

void alterar(int *p)
{
    *p = 100;
}

int main(void)
{
    int numero = 10;

    printf("Antes: %d\n", numero);

    // Passamos o endereco
    alterar(&numero);

    printf("Depois: %d\n", numero);

    return 0;
}

06 • Aritmética de ponteiros

O que acontece quando fazemos p++?

O ponteiro passa para o próximo elemento do tipo para o qual aponta.

Para um array de int


int *p = numeros;

p++;

Agora p aponta para o próximo elemento do array.

Regra importante


p + 1
↓
próximo elemento

O deslocamento considera o tamanho do tipo apontado.

07 • Segurança

E se o ponteiro não apontar para nada?

Podemos utilizar NULL para indicar que o ponteiro não possui um endereço válido associado.

⚠️
Nunca desreferencie um ponteiro NULL.

Fazer *p quando p não aponta para uma região válida pode causar comportamento indefinido. 

int *p = NULL;

if (p == NULL)
{
    printf("Ponteiro nao inicializado.\n");
}
