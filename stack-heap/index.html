🧠 O que é uma estrutura de dados?

Em computação, uma estrutura de dados é uma forma de armazenar e organizar os dados para que possam ser utilizados de maneira eficiente.

Uma estrutura de dados estabelece uma organização lógica entre dados e operações, buscando resolver determinado problema de forma eficiente.

Esse tema é fundamental na Ciência da Computação porque uma organização adequada pode reduzir o custo de execução de algoritmos em termos de tempo de execução, consumo de memória ou ambos.

📦 Alocação automática — Stack

Em C, muitas variáveis locais possuem duração automática: a memória necessária é gerenciada automaticamente quando a função é chamada e liberada quando seu escopo de execução termina. Em implementações comuns, essa região é associada à Stack (pilha).

É importante fazer uma distinção: no uso cotidiano de cursos introdutórios, essa situação às vezes é chamada de “alocação estática”. Tecnicamente, em C, duração de armazenamento estática é outro conceito, relacionado a objetos que existem durante toda a execução do programa. Por isso, nesta página usamos o termo mais preciso alocação automática / Stack.

⚡ Características

  • Gerenciamento automático da memória das variáveis locais.
  • Tempo de vida associado à execução do escopo/função.
  • Arrays de tamanho fixo possuem elementos contíguos na memória.
  • Não exige malloc() e free() para cada variável automática.
  • Em geral, o acesso e gerenciamento são muito eficientes.

📌 Atenção

A Stack não deve ser tratada como sinônimo de toda memória “estática”. Além disso, detalhes como tamanho máximo e organização exata da Stack dependem do sistema, compilador e arquitetura.

🔗 Alocação dinâmica — Heap

Como funciona?

Na alocação dinâmica, o programa solicita memória durante a execução. Em C, malloc(), calloc() e realloc() são usados para obter ou redimensionar blocos de memória, enquanto free() os libera.

O bloco alocado permanece válido até ser liberado ou até o processo terminar. Sua existência não depende diretamente do escopo da variável ponteiro que o referencia.

⚠️ Responsabilidade

O programador deve verificar se a alocação foi bem-sucedida e liberar a memória quando ela não for mais necessária.

Se um bloco ficar inacessível sem ser liberado, pode ocorrer um memory leak.

🚨 Ponteiro após free()

Depois de free(ptr), o bloco apontado deixa de estar disponível. O valor de ptr pode permanecer na Stack, mas ele não deve mais ser dereferenciado. Uma prática segura é atribuir ptr = NULL após a liberação quando o ponteiro continuar em uso no escopo.

🔧 Exemplo de Heap em C

O exemplo abaixo aloca espaço para cinco inteiros, verifica o resultado e libera o bloco corretamente.

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *dados = malloc(5 * sizeof *dados);

    if (dados == NULL) {
        return 1;
    }

    dados[0] = 10;
    dados[1] = 20;

    free(dados);
    dados = NULL;

    return 0;
}

Observação: Stack e Heap são termos de implementação muito comuns, mas a linguagem C não exige uma organização física específica com essas duas regiões. A forma exata depende do sistema e da implementação.

🎯 Resumo

Stack: região normalmente usada para chamadas de funções e objetos de duração automática em implementações comuns.
Heap: área usada para armazenamento dinâmico solicitado durante a execução.
malloc(): solicita um bloco de memória não inicializado.
free(): libera um bloco obtido por alocação dinâmica.
Ponteiro: objeto que armazena um endereço ou valor usado para referenciar uma região de memória.
Memory leak: bloco alocado que permanece reservado sem poder ser utilizado novamente pelo programa.
Stack overflow: esgotamento da capacidade disponível para a Stack em uma implementação.
Fragmentação: distribuição de blocos livres e ocupados que pode dificultar futuras alocações.
